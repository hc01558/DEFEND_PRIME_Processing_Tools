## DEFEND PRIME Processing Tools
This repository contains the data processing tools used by the DEFEND PRIME study to:
- Validate the raw data extracts from EMIS Web and TPP SystmOne for extraction software development.
- Validate the software that performs the transformation, value selection and anonymisation processes for TPP SystmOne and EMIS Web extracts.
- Perform the required value selection and anonymisation processes on the raw EMIS Web data extract produced by the study's XML file.
- Transform raw TPP SystmOne data extracts into the EMIS Web format, using the extracts generated by the search and report output configuration available to DEFEND PRIME group members in TPP SystmOne.
- Perform the required value selection and anonymisation processes on the TPP SystmOne extract once converted into the EMIS Web format.
